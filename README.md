## 🚀 クイックスタート

### 前提条件
- Python 3.7 以上
- モダンブラウザ（Chrome, Safari, Firefox, Edge）
- pandas, openpyxl ライブラリ

### セットアップ

1. **リポジトリをクローン**
```bash
git clone https://github.com/DrMongsang/ai_katagami.git
cd ai_katagami
```

2. **必要なPythonライブラリをインストール**
```bash
pip install pandas openpyxl
```

3. **Excelデータが存在することを確認**
```bash
ls -lh お直し_仕上がり寸含む_分析用_2025年9月.xlsx
```

4. **ExcelデータをJSON形式に変換**
```bash
python3 convert_excel_to_json.py
```

出力例：

## 📖 使い方

### 1. フィルタ機能

#### 店舗フィルタ
- 「全店舗」または特定の店舗を選択
- 複数選択可能（Ctrl/Cmdキー + クリック）
- 上位店舗例：
  - FABRIC TOKYO 有楽町（銀座）: 3,388件
  - FABRIC TOKYO 新宿: 3,266件
  - FABRIC TOKYO 大阪梅田: 2,292件

#### 担当者フィルタ
- 「全担当者」または特定の担当者を選択
- 複数選択可能
- 上位50名が選択肢に表示

#### 期間フィルタ
- 開始日・終了日を選択
- カレンダーUIで簡単選択
- クイック選択（予定）：最近1ヶ月、3ヶ月、6ヶ月、1年、全期間

#### フィルタの適用
1. 各フィルタで条件を選択
2. 「フィルタ適用」ボタンをクリック
3. ダッシュボードが即座に更新される
4. 「リセット」ボタンで全フィルタをクリア

### 2. ダッシュボード表示

#### KPIカード
画面上部に4つのKPIを表示：
- **総件数**: フィルタ適用後の注文総数
- **ユニーク顧客数**: フィルタ適用後の顧客数
- **出腹懸念以上**: 出腹懸念・出腹・強出腹の合計
- **お直し重症（D）**: お直し分類Dの件数

#### グラフ表示

**1. 体型区分の分布（円グラフ）**
- 5種類の体型区分を色分け表示
- マウスホバーで詳細情報（件数・比率）を表示
- 色分け：
  - 緑：非出腹
  - 黄：出腹懸念
  - オレンジ：出腹
  - 赤：強出腹
  - 青：BMI肥満だが非出腹

**2. 身長区分の分布（棒グラフ）**
- H1〜H5の5区分を表示
- 各区分の身長範囲も表示

**3. お直し分類の分布（円グラフ）**
- A/B/C/Dの4分類を表示
- フィルタ適用後のリアルタイム集計

**4. 月別推移（折れ線グラフ）**
- 2023年1月〜2025年11月の推移を表示
- フィルタ適用後の月別件数

#### ランキングテーブル

**店舗別ランキング（Top 10）**
- 件数の多い順に上位10店舗を表示
- お直し分類Dの割合を表示
- 色分けバッジ：
  - 緑：30%未満
  - 黄：30-40%
  - 赤：40%以上

**担当者別ランキング（Top 10）**
- 件数の多い順に上位10名を表示
- お直し分類Dの割合を表示

### 3. データエクスポート

#### CSV出力
1. フィルタを適用（任意）
2. 画面右上の「CSV出力」ボタンをクリック
3. フィルタ適用後のデータがCSV形式でダウンロード

**出力項目:**
- 注文ID
- 顧客ID
- 注文日
- 出荷日
- お直し日
- 店舗
- 担当者
- お直し分類
- 注文区分
- カテゴリ
- アイテム

**ファイル名形式:**
```
belly_analysis_YYYY-MM-DD_HH-MM-SS.csv
```

## 📝 出腹判定基準（参考）

### 判定指標（5つ）
1. **WHtR** (Waist-to-Height Ratio): ウエスト ÷ 身長 ≥ 0.50
2. **WHR** (Waist-to-Hip Ratio): ウエスト ÷ ヒップ ≥ 0.90（男性）/ 0.85（女性）
3. **W/B比**: ウエスト ÷ バスト ≥ 0.95
4. **PW/B比**: パンツウエスト ÷ バスト ≥ 0.97
5. **WT-W差**: ウエストトップ − ウエスト ≥ 4cm

### 判定ルール
- **0-1個該当**: 非出腹
- **2個該当**: 出腹懸念
- **3個該当**: 出腹
- **4-5個該当**: 強出腹
- **BMI ≥ 25 かつ非出腹**: BMI肥満だが非出腹（マッチョ体型）
